Este repositório tem como objetivo ter códigos utilizando framework Angular. 

curso-cod3r está utilizando angular 9
masterclass-cod3r está utilizando angular 21 

## Comandos básicos do angular


```markdown
# Criar componente #
ng g c <caminho-do-componente a ser criado>
```
```markdown
# Criar componente sem testes #
ng g c <caminho-do-componente a ser criado> --skip-tests
```
